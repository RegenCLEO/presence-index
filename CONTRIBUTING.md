# Contributing

## Propose a change to the method

Open an issue with the **Proposal** template, or email contact@regencleo.ai. Every proposal gets a published response with reasons. Section 9 of [METHODOLOGY.md](METHODOLOGY.md) describes how proposals are decided and released.

## Report a fault in the code

Open an issue. Say which command you ran, on which version tag, and what you expected. Attach the smallest panel file or input that shows the fault. Do not attach API keys or raw vendor responses.

## How the code is published

CLEO develops this code in a private repository. This public repository receives tagged snapshots only. Each snapshot is one commit, named in [CHANGELOG.md](CHANGELOG.md), and each published ranking names the tag that produced it.

Pull requests are not accepted, because a merge here would be overwritten by the next snapshot. Put a code change in an issue instead, as a description or a patch. A change we take is credited to its author in the changelog.
