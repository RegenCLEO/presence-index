# Security

Report a vulnerability by email to contact@regencleo.ai, with "Security" in the subject. Do not open a public issue for it.

Say what you found, where, and how to reproduce it. We reply within five working days and tell you what we will do.

This repository holds the method, the reference calculator and the public scan code. It holds no keys and runs no service. A report about CLEO's product or website is welcome at the same address.
